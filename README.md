# GitHub User Activity CLI

A Python command-line application that fetches and displays recent public activity of a GitHub user using the GitHub REST API.

## Project URL

https://github.com/Abhishekak02/github-user-activity

## Features

- Fetch recent public GitHub events.
- Display user activity in the terminal.
- Handle API errors and empty responses.

## Requirements

- Python 3.10+
- Internet connection

## Usage

```bash
python main.py Abhishekak02
```

Replace `Abhishekak02` with the GitHub username you want to check.

## API Used

https://api.github.com/users/USERNAME/events

## Future Improvements

- Support additional GitHub event types.
- Improve output formatting.
- Add more error handling.
